三件平时要开好几个窗口的事。

01

Address already in use

netstat 看得到端口，taskkill 才杀得掉进程。这里按端口号一次列出占用者，确认后结束整棵进程树。

02

提交空间见底

页面文件耗尽时，IDE 会在毫无预兆的情况下崩。监控和崩溃日志里的 AvailPageFile 是同一套数字。

03

磁盘红了才发现

临时文件、包缓存、大文件分开列。默认只勾缓存类，删除前再确认一次，不进回收站。

十一个工具，分成看系统、查文件、做转换。

看这台机器

端口占用、提交空间趋势、Windows 服务启停、磁盘容量和垃圾清理。危险操作都要再点一次确认。

在目录里找字

递归搜代码和文本，跳过 .git、压缩包和二进制。结果按代码、配置、其他文本分组。只读，不改文件。

留在浏览器里的转换

  • JWT 解码，可选本地验签
  • JSON 格式化、压缩、校验
  • 时间戳、Base64、UTF-8 转义
  • 直连读取 HTTPS 证书

双击打开，浏览器进本机页面。

Windows

单个 OneKit.exe。第一次会请求管理员权限，同意后打开 127.0.0.1:8765。取消授权则程序不启动。

下载 OneKit.exe

macOS

解压后双击 OneKit.app。若被拦截，在 Finder 里右键该应用再选「打开」。操作系统服务需要 sudo。

下载 OneKit-macos.zip

源码

Python 3.8+，标准库，没有第三方包。运行 python server.py，同一地址。

github.com/yujiaao/port-occupancy-manager

只绑定本机，不上传。

127.0.0.1服务不监听外网。JWT、JSON、时间戳这些转换在浏览器里完成。

不碰关键进程拒绝结束 PID 0、PID 4 和工具自己。受保护的系统服务按钮是灰的，后端也会拒绝。

MIT仓库公开。Windows 与 macOS 安装包放在 dist，需要 Python 时直接拉源码。
